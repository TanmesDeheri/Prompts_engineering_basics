# Foundational Prompt Log

## Task 1: Text Summarization

### Prompt Input

```text
Summarize the text below in exactly three bullet points.
Text: "Remote work has rapidly expanded, introducing both opportunities and obstacles
for modern businesses. While remote employees benefit from increased flexibility and
reduced commute times, managers often face communication barriers, tracking
difficulties, and security risks associated with home networks."
```

### ChatGPT Output

```text
- Remote work has expanded rapidly among modern businesses.
- Employees gain flexibility and shorter commute times.
- Managers face communication, productivity tracking, and home-network security challenges.
```

## Task 4: Professional B2B Email Editing

### Prompt Input

```text
Act as an Editor. Rewrite the draft text below to sound like a professional, polite B2B
email sent to a client.
Draft: "hey, sorry we are late on the report. it had bugs. we will send it tomorrow.
thanks."
```

### ChatGPT Output

```text
Certainly — here’s a polished B2B version:

Dear [Client Name],

Please accept our apologies for the delay in delivering the report. We encountered some technical issues that required additional time to resolve and ensure the report meets our quality standards.

We expect to send you the completed report by tomorrow. Thank you for your patience and understanding.

Best regards,
[Your Name]
```
